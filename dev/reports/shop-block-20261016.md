# 商店街一区画の追加

中央通りの東側にある6棟に店舗外観を追加。食堂、パン屋、青果店、喫茶店、書店、商店の架空店舗です。512×512の共有看板アトラス、入口、ガラス窓、シャッター、ひさし、バルコニー、室外機を配置しました。

中央通りの歩道・縁石・側溝・舗装目地、電柱・電線・街灯、2台の自販機、カーブミラーを追加。電柱・街灯・自販機は走行判定にも追加しています。交差点を避けて縁石を配置し、車道は従来の幅を維持します。

日光の色と霧を調整。1024pxの静的シャドウマップを初回だけ更新し、軽量モードでは影を無効化。静的な箱型パーツはInstancedMeshで色別に集約。シーンのトップレベル描画オブジェクトは52、インスタンスは1880。実際のGPU描画負荷を計測した数字ではありません。

街の構築・数値・コリジョン、走行モデル、DOM操作、ビルドを検証。実ブラウザ描画・iPhone実機の外観とFPSは未確認です。
