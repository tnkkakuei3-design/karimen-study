# 共通のタブ・ボタン（2026-10-12）

同じ操作の見た目が画面によって変わらないよう、模試・学習・復習・結果・図解ノート・設定・ホーム画面追加案内を整理。

| 役割 | 共通ルール |
| --- | --- |
| タブ | 選択時は青文字と下線。学習の2タブと下部ナビゲーションで揃える |
| 絞り込み・選択 | `.seg`。44px以上、丸枠、選択時は淡い青と青枠 |
| 主要操作 | `.btn`。48px以上、16px文字、角丸10px、青地に白文字 |
| 戻る・閉じる・キャンセル | `.btn.secondary`。明るいテーマは白地、ダークはテーマの面色。ヘッダーの戻るは `.compact`（44px以上・14px文字） |
| 補助操作 | `.textbtn`。44px以上、14px文字、青文字 |
| 途中再開・10問への入口 | `entryCard()`。左の青線、アイコン、見出し・説明、右のシェブロンを共有 |

色・高さ・角丸・太さは共通変数で管理。模試、結果、設定の選択ボタンを下線式から共通の丸枠にし、学習だけの絞り込み上書きを削除。カードのシェブロンは18px、操作ボタン内のアイコンは20px。回答の○×は専用の大きさと正誤の色を保つ。

問題・採点・復習予定・保存方式は変更しない。途中保存は引き続き全体で1件。

検証：

- `test-ui.mjs` 成功（全10回の模試、500問、130画像の対応、再開・採点・記録、10問常設）。
- `test-home-install.mjs` 成功（初回案内、閉じる・再表示、iOS/Androidの分岐、記録書き出し）。
- DOM/CSS監査でライト・ダークそれぞれ5画面の選択ボタン、3画面の再開カードの共通スタイルを確認。
- 構文検査と `git diff --check` 成功。
