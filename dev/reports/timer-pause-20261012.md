# 模試タイマーの自動停止（2026-10-12）

## 変更内容

- 模試の問題画面が表示され、ウィンドウにフォーカスがある間だけ残り時間を減らす。
- `visibilitychange`、`blur`、`pagehide` で停止・保存し、復帰時は条件を満たす場合だけ再開する。
- 「中断」で一覧へ戻った場合と再読み込み後は、ユーザーが「続きへ」を押すまで停止する。
- 回答、問題順、現在位置と残り時間を保持し、書き出し・読み込みにも残り時間を含める。
- 表示中は5秒ごとに残り時間を保存し、終了イベントが届かない場合も直近の保存値から復元する。
- 旧版の固定終了時刻のみを持つ途中記録は、移行時点の残り時間を保存する。すでに時間切れの記録に時間は追加しない。
- 復習の30分待ちは実時間で進む既存仕様を維持する。
