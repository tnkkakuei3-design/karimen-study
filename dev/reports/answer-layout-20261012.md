# 回答後の画面改善

ユーザーが選んだ「正解・解説を先に表示する案」を基本に、明確な原則と例外を分ける要点カードを組み合わせた。

- 学習・復習・解説付き練習の回答後は、結果 → 覚えるポイント → 問題文の順に表示する。
- 自分の回答と正解を文字で区別し、大きな回答ボタンは回答後に結果表示へ切り替える。
- 問題文は最初から開いた折りたたみ欄に全文を残す。問題画像、画像拡大、図解、参考問題と公式資料へのリンクも維持する。
- 既存の解説文を使用し、確認済みの9問のみ原則・例外を分ける。その他の問題は要点と補足として表示し、条件を推測して追加しない。
- 正解、不正解、自信なし、復習予定、ダークモードに対応する。回答結果へフォーカスを移し、前へ戻る際も結果を読み上げられる。
- 出題データ、採点、復習間隔、保存形式、模試中の回答画面は変更していない。
- 基準コミット: `57d522a5a4ca0f42a0db8fe1f9dc99a0b60840d7`。直前の模試採点・タブ切替・復習再開・日本語検索修正を含む。

## 検証

`npm test` 成功。500問の回答前・回答後の問題文、130問の画像保持、正解・不正解・自信なし、再読み込み後の再開、前後移動時の重複記録防止を確認。既存の採点・移行・タイマー・模試回答秘匿・解説付き50問完走も成功。

`dev/visual-review.html` に回答前、不正解、正解、画像あり、自信なしの表示確認を追加。検証画面の記録は隔離したメモリに保存し、実際の学習記録には触れない。
