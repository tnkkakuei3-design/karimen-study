# 仮免学科ドリル

教習問題1〜10の各50問、合計500問を、模試・学習・復習で使う静的Webアプリです。
公開先: https://tnkkakuei3-design.github.io/karimen-study/

## 使い方

- **模試**: 第1〜10回から選択。各回の50問を開始するたびにランダムな順番で出題・30分。途中再開では同じ順番を保ちます。45点以上でアプリ内の合格、48点以上で目標達成、50点で満点の花丸。解説は採点後に表示します。
- **学習**: 同じ500問を分野別に原則10問ずつ学習。1問ごとに解説を表示します。図解ノート47テーマもここから開けます。
- **復習**: 実際の誤答・自信なしを共通IDで集約。未回答は正答率や復習予定に加算しません。初回の誤答・自信なしはすぐ復習でき、復習後は30分あけて自信のある正解を2回重ねると卒業します。復習の間違い・自信なしは回数をリセットして30分後に再挑戦。復習開始ごとに順番を変え、途中再開では維持します。予定前の正解は回数を進めません。
- 各回の詳細から、制限時間のない「解説付き50問練習」も教材の順番で始められます。模試と別の成績として保持します。

公式試験問題の再現や合格を保証するものではありません。28問は出典付きの代替問題、9問は補足です。各回の開始前と該当設問で表示します。補足も各回の50問に含めます。

## 構成

ビルド不要。ルートを静的配信します。npm依存は検証専用で、利用者の端末では不要です。

- `questions.js`: 有効500問、保管408問、各回の順序・内容版、追加図の対応表
- `learning-content.js`: 既存47テーマのノート・図解・参照資料
- `model.js`: 保存、旧記録の移行、採点、復習スケジュール
- `visuals.js`: 既存の確認済み設問図・画像出典・花丸・ノート見本
- `app.js`, `index.html`, `styles.css`: 3タブ、問題、結果、ノート、設定の画面
- `image-*.png` と `data/assets/`: 既存図と追加99画像（104設問で使用）

## 問題と内容版

有効IDは301〜800。1回50問を維持し、類似する設問を回をまたいで削除しません。3〜10の旧 `set14〜21` は新しい回番号ではありません。`WORKSHEETS.orderedIds` と `worksheet` を正とします。

新規出題は `Q` の500問のみ。`ARCHIVED_Q` の408問は過去の記録表示用です。ノートからの練習も有効500問に限定します。

`isReplacement`, `replacementSource`, `sourceRef`, `isSupplemental` を保持してください。設問画像は `ADDED_ART` と既存 `IMGQ` / `VISUALS` から表示し、解説用の図や参考問題リンクは解答後に表示します。

本文・正答・図の意味を変えるときは、その回の `contentVersion` と共通の `CONTENT_VERSION` を更新します。現在の内容版は引継ぎ時の本文・正答・説明・図ID・代替/補足フラグ・追加画像ハッシュに基づきます。既存画像や共通図の意味を変更する場合も内容版の更新が必要です。IDの変更や再利用は禁止です。

## 学習記録

新しい保存先は `karimen-study-v4`。旧 `karimen-study-v2` と `karimen-drill-miss` は削除・上書きしません。v4がないときだけ旧記録を移行します。旧記録との継続同期はしません。

- 有効500問の回答・誤答・復習予定は引き継ぎます。
- 旧50問練習の得点と花丸は `guidedResults` に保持します。30分模試の `mockResults` とは混算しません。
- 除外408問、旧判定A〜C、旧ランダム模試、対象外の途中セッション、未知IDは `legacyArchive` に保管します。設定から閲覧・書き出しできます。
- 当時の得点 `scoreSnapshot` は現在の正答で再計算しません。前回差は同じ回・内容版・採点方式だけを比較します。
- 最高点は直近10回から落ちても保持します。同点は「更新」と表示しません。
- 同じ試行は `attemptId` で重複保存を防ぎます。
- 手動の途中終了は履歴に残し、回答した問題だけで正答率を表示します。50問の合否・最高点・前回比較には含めません。未回答は結果画面で別に確認・学習できます。
- `statsPolicy: 1` では未回答を学習統計に加算しません。以前のv4記録は保存済みの回答履歴に基づき一度だけ補正し、補正前の集計を保管します。実際の回答の時系列を復元できない旧記録では、既存の復習予定を保守的に保持します。
- 模試の出題順は新規開始時だけFisher–Yatesで並べ替え、`session.ids` と回答・フラグを同じ位置で保存します。再読込み・再開・インポートでは再抽選しません。各回50問の所属を順序に依存せず検証し、従来の順番で保存した途中記録も継続できます。結果画面には出題順と元の回・問題番号を併記します。
- 模試は `endAt` を引き継ぐため、リロードや中断でも延長しません。時間切れは50問で一度だけ採点しますが、未回答は学習の正答率や復習予定に加算しません。
- 保存失敗は画面に表示します。壊れたJSONは保管し、保管できない場合は元データへの上書きを止めます。
- 書き出しには途中の回答と以前の記録も含みます。読込み前の現記録も保管します。
- 別タブの更新を受けたタブは操作を止め、再読み込みを案内します。

## 検証

Node.js 24.15以降を使用します。

```sh
npm ci
npm test
```

依存なしで実行できる確認:

```sh
node validate.mjs
node test-progress.mjs
```

`test-ui.mjs` はJSDOMによるDOM操作の統合テストで、見た目の検査とは区別します。
