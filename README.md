# 仮免学科ドリル

普通仮免許の学科対策用の静的Webアプリです。公式試験問題の再現や合格を保証するものではありません。

## 構成
- index.html: ページと案内文
- styles.css: 表示スタイル
- questions.js: 練習・実力テストの問題データ
- learning-content.js: 図解・ノート・参照資料
- app.js: 出題、採点、復習、保存、画面表示
- image-*.png / jpg: 画像（出典は各画面・フッターに記載）

ビルド不要。これらのファイルを同じディレクトリに置き、静的Webサーバーで配信してください。

## 問題の追加
questions.js の Q に問題を追加します。必須: id（全問題で一意の整数）、topic、q、a（真偽値）、ex。図解がある場合は fig を指定します。章別出題用に chapter / section / concept を付けます。仮免の模試対象外は chapter:null とします。
問題集として表示する場合は practiceSet に正の整数を指定してください。同じ番号の問題が1セットになり、一覧は自動生成されます。IDの昇順で出題します。既存IDの変更・再利用は学習記録の意味を変えるため避けてください。
図が必要な問題は app.js の画像対応・learning-content.js の図解も合わせて追加してください。実力テストの問題は ASSESSMENT_Q に分離しています。

## 学習記録
localStorage に保存します。アプリから回答記録をサーバーへ送信する機能はありません。旧版と同じ保存キー・問題IDを維持しています。記録の書き出し・読み込みは設定から行えます。

保存形式は version 3 を維持し、任意項目 practiceResults を追加しています。version 2・3の記録を引き継ぎます。教習問題は、そのセットの50問練習を完了したときに得点・回答を保存します。セットごとの最高点と直近10回を保持し、最高点45点以上で一覧に合格の花丸を表示します。過去の問題別回答数から合格を推定することはありません。得点・合格記録はJSONの書き出し・読み込み・初期化にも含まれます。

復習は reviewAt が現在時刻以前の問題を「今日の復習」、それ以降を「次回の復習」と表示します。従来どおり、24時間以上あけた自信のある正解を2回重ねると卒業します。予定前に正解しても卒業までの回数は進みません。日付と時刻は利用中の端末のタイムゾーンで表示します。

## 素材
第三者の画像・教材を含みます。出典表示は包括的な再利用許諾を意味しません。再配布や別用途での使用前に各権利者の条件を確認してください。

## 検証
Node.js で `node validate.mjs` を実行すると、ID重複・必須項目・テスト問題数・画像ファイル参照を確認できます。
`node test-progress.mjs` では、旧版の記録・途中の練習の引き継ぎ、合格基準、最高点の保持、復習時刻の境界、JSONの読み込みを確認します。
